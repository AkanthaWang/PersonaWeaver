<h2 align="center">PersonaWeaver · 灵织</h2>

## 项目定位

PersonaWeaver 是面向长篇小说、剧本与角色扮演创作的本地工作台。
以 LangGraph 为运行时，围绕角色一致性构建 Agent Harness，将资料提取、知识检索、
角色模拟、小说片段与剧本单场景生成连接为可编排、可恢复、可追溯的创作闭环。

角色对话和内容生成运行在持久化消息树、分支记忆与上下文预算管理之上：
先使用已提取资料，必要时按需调用原文检索工具；草稿通过一致性校验后才进入正式历史。
原著、角色卡与分支经历分别管理，分支创作不能覆盖原著事实。
一致性依靠运行时门禁与证据追溯增强，不意味着模型能绝对识别所有语义冲突。

## 核心能力

- **资料与角色资产**：文档导入、章节阅读、带引文的知识提取和 Markdown 角色卡。
- **资料优先的工具检索**：角色、事实、关系、事件和世界设定优先，原文按明确缺口补查。
- **连续创作**：角色对话、小说片段和剧本场景沿会话续写，从历史节点探索不同剧情。
- **持久状态**：历史消息、增量压缩、不可变分支记忆，以及可显式恢复的执行检查点。
- **可追溯发布**：阶段进度、工具轨迹、来源定位、冲突修订与发布前一致性校验。

## 技术栈

- **前端**：Vue 3、Vite、Pinia、Vue Router、Element Plus。
- **后端**：Python、FastAPI、Pydantic。
- **Agent 运行时**：LangGraph、SQLite checkpointer、统一模型与工具适配层。
- **持久化**：SQLite 消息树、记忆版本、提取成功单元检查点与本地文件。
- **模型协议**：OpenAI 兼容、Responses、Ollama，以及严格 JSON 工具动作兼容路径。
- **检索**：本地 SQLite FTS5 中文关键词检索；会话 Embedding 默认暂停，独立向量接口保留。

运行方法、接口、状态语义与验收结果见 [项目详细文档](docs/DETAILS.md)。
